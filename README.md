# Alexadlu.github.io

这是一个用于 GitHub Pages 的个人学术主页，使用纯 HTML、CSS、JavaScript 构建，不依赖后端或构建工具。

## 文件结构

```text
.
├── index.html   # 页面内容
├── style.css    # 页面样式
├── script.js    # 手机端导航和滚动动画
└── README.md    # 项目说明
```

## 如何修改个人信息

请在 `index.html` 中搜索 `TODO`，逐项替换为真实信息：

- 当前身份、单位、邮箱
- 教育背景
- 研究方向
- 论文发表
- 项目经历
- 荣誉奖项
- 联系方式

## 如何发布

进入 GitHub 仓库：

```text
Settings → Pages
```

推荐配置：

```text
Source: Deploy from a branch
Branch: main
Folder: /root
```

保存后，等待 GitHub Pages 构建完成，访问：

```text
https://Alexadlu.github.io/
```
